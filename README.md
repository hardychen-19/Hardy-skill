# Hardy-skill

模块化的 X 创作与运营技能项目。当前先发布数据复盘模块；其他能力完成、验证后逐个加入。

## 当前可下载

| 目录 | 作用 | 状态 |
| --- | --- | --- |
| `hardy-skill/` | 总入口，路由已安装模块 | 可安装 |
| `skills/hardy-x-review/` | X Analytics 数据复盘 | 第一版指令型技能 |

`hardy-x-review` 会指导 AI 分析账号总览和内容 CSV，区分真实净涨粉与单帖归因关注，输出下一次内容实验。它目前没有内置 X 登录器、定时任务或一键导出程序；这些能力依赖运行它的应用和用户账号权限。

总入口使用[固定工作区协议](hardy-skill/references/artifact-protocol.md)连接技能。首次使用时默认在用户主目录创建 `HardySkill`，也可由用户指定位置；配置一经建立，后续技能复用同一目录。每个模块写自己的固定产物类别目录，并用清单记录产物类型、版本、来源和状态。只有类型与状态兼容的模块才能直接组成工作流。

## 规划中

- `hardy-x-writing`：写作风格、短推、线程、长文。
- `hardy-x-cover`：X 长文封面和配图。
- `hardy-x-publish`：发布草稿、排期与实际发布。

规划中的模块尚未包含在发布包中。每个模块以后都将有独立下载包；总项目也会同步更新。

## 安装

只要复盘能力，就把 `skills/hardy-x-review/` 复制到 Codex 的 skills 目录。想要统一入口，再安装 `hardy-skill/`。两个目录均包含独立的 `SKILL.md`，可以分别安装。
