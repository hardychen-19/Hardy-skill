# Hardy Skill 模块规划

发布原则：每个能力是独立的 Skill 目录，包含自己的 `SKILL.md`，可单独下载；总入口只路由实际发布并安装的模块。未来新增模块不要求用户重装已有模块。

| 模块 | 计划能力 | 状态 |
| --- | --- | --- |
| `hardy-x-review` | X Analytics 复盘、账号净涨粉、内容归因、实验建议 | 已有第一版指令型技能 |
| `hardy-x-writing` | Hardy 写作风格、短推、线程、长文 | 规划中 |
| `hardy-x-cover` | X 长文封面与配图 | 规划中 |
| `hardy-x-publish` | 审核后的发布草稿、排期与 X 发布 | 规划中 |

复盘模块在真实账号上需要合法的 X Analytics 访问方式或用户提供的 CSV。是否能自动下载由运行环境决定，不由技能文本保证。后续模块完成后再更新总入口路由与发布目录。
