# Hardy Skill 模块规划

发布原则：每个能力是独立的 Skill 目录，包含自己的 `SKILL.md`，可单独下载；总入口只路由实际发布并安装的模块。未来新增模块不要求用户重装已有模块。

模块之间使用[产物与工作流协议](artifact-protocol.md)连接：用户首次运行时建立一个固定工作区，技能用类型化产物清单传递结果，总入口按输入/输出类型组成流程。

| 模块 | 计划能力 | 状态 |
| --- | --- | --- |
| `hardy-x-review` | X Analytics 复盘、账号净涨粉、内容归因、实验建议 | 已有第一版指令型技能 |
| `hardy-x-writing` | Hardy Chen 中文长文、提纲、续写、改写与审校；重点支持 X 长文 | 已发布指令型技能；短推与线程不在本版范围 |
| `hardy-x-cover` | X 长文封面与配图 | 规划中 |
| `hardy-x-publish` | 审核后的发布草稿、排期与 X 发布 | 规划中 |

复盘模块在真实账号上需要合法的 X Analytics 访问方式或用户提供的 CSV。是否能自动下载由运行环境决定，不由技能文本保证。后续模块完成后再更新总入口路由与发布目录。

## 插件合集

`.claude-plugin/marketplace.json` 按宝玉合集的方式注册一个插件，技能列表只包含已完成的总入口、复盘和写作目录。总入口保留现有 `hardy-skill/` 路径，子技能放在 `skills/`；可单独复制目录安装，也可安装合集。未完成的封面和发布不注册。

写作内的可选参考按需读取，不把多套文风全文一起加载。模块产物协议由总入口维护，写作目录携带同版本副本以支持独立安装，验证脚本检查副本一致性。
