# 选择正文配图主题

四套主题只改变视觉表达，共用选知识点、真实截图、事实边界、验收和 Markdown 交付流程。可用于任意适合的文章题材，不把“科技”等名字当内容限制。

| 主题 ID | 名称 | 视觉 | 规则 |
| --- | --- | --- | --- |
| soft-3d | 柔和立体（默认） | 暖白、哑光体积、蓝灰与奶油色，沿用 Hardy 正文风格 | [柔和立体](themes/soft-3d.md) |
| ink-notes | 手绘笔记 | 米白纸、细墨线、少量蓝黄点色，轻松清楚 | [手绘笔记](themes/ink-notes.md) |
| watercolor | 清淡水彩 | 留白、透明水彩、柔和绿色与蓝色，温和自然 | [清淡水彩](themes/watercolor.md) |
| midnight-tech | 深色科技 | 深蓝底、简洁线光、青蓝高对比，克制技术感 | [深色科技](themes/midnight-tech.md) |

用户本次指定主题优先，其次读取个人档案 active_theme，没有时用 soft-3d。已知主题直接执行，不要求反复选择。用户想比较时展示本页对应预览，选择前可只分析。主题未匹配时解释可选项，或按用户明确自定义的视觉要求工作；自定义偏好记入交付清单，不伪装成内置主题。

主题选择用法：`用 hardy-x-illustrations，主题选手绘笔记，为这篇文章配图。` 首次也可同时上传照片与文章，不需自行编写完整图像提示词。

当前预览使用相同示例知识点：“AI 起草 → 人核实 → 根据反馈修改”。这些是生成演示，角色是作者示例，不代表用户角色，也不代表任意照片都能逐像素复现。完整提示词与演示记录在仓库 examples/illustration-themes；单独安装包内携带预览及本页主题规则。
