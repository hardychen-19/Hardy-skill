# Hardy X 封面提示词蓝图

每张封面都要从具体文章编译出一份完整提示词，不能只把“封面要求”和“风格词”拼在一起。参考 `punk-cover` 的任务字段、标题层级、内容摘要、可读性和单次生成文件绑定方法；保持提示词、分镜与成图属于同一篇文章。此模块不加载 Punk 的私有风格库，固定采用 `style-guide.md` 描述的 Hardy 网站视觉。

## 生成前提取的字段

- **文章标题**：Markdown 标题原文，逐字保留。标题很长时用字号、换行和版位解决；不能擅自改成更吸睛的短标题。
- **简短语境**：从全文提炼 1–3 句上下文，不粘贴全文，也不扩写未提供的个人经历。
- **视觉主体**：能承载文章中心主题的物体、人物动作或概念场景。
- **读者与情绪**：主要面向谁，应该呈现怎样的情绪。
- **核心隐喻**：只选择一个能解释观点的视觉关系或变化。
- **禁用元素**：用户特别排除的元素，以及可能误导读者的伪造界面、数据、引语或身份肖像。
- **版式规格**：默认 X 文章封面，5:2，目标 1200×480；用户另给平台、比例或尺寸时，以用户值为准。

## 完整提示词结构

将以下字段改写为自然、可执行的一份封面生成提示词；不要保留方括号占位符：

```text
# Hardy X 文章封面

创作一张单幅中文 X 长文封面，比例 {ratio}，目标画幅 {dimensions}。

## 文章信息
- 完整标题（逐字保留）：{title}
- 正文语境摘要：{summary}
- 面向读者：{audience}
- 画面情绪：{mood}
- 视觉主体：{subject}
- 核心隐喻：{metaphor}
- 禁用内容：{banned_elements}

## 画面目标
第一眼让读者识别文章主题，第二眼理解其中的核心关系或变化。只表达一个主视觉判断，不用长文正文填满画面，不做课程宣传页、PPT标题页或模板化信息图。

## 品牌视觉与版式
应用 Hardy 当前个人网站的黑白灰现代编辑视觉，采用高对比、清楚层级、留白和简洁的现代漫画/编辑插画语言；本篇可有一处克制的低饱和强调色。主题主体与标题版位必须共同构图，生成图像应在预留区域保持干净，不出现随机字符或假的标题。

## 标题处理
画面最终必须出现完整且正确的文章标题。先生成无字背景；再通过可控排版工具叠加标题，不让图像模型代写中文。使用与背景有充分对比的现代中文无衬线字体，按阅读顺序自然换行；字形完整、可读，不裁切、不挡住关键主体。默认不新增副标题。

## 构图
- 主视觉位置：{subject_placement}
- 标题位置与行数：{title_placement}
- 视线顺序：标题 → 主体/隐喻 → 少量背景细节
- 留白与背景：为标题留出足够干净区域，画面缩小后标题和主体仍可辨认
- 层次：避免不必要的边框、贴纸、面板和微小装饰

## 禁止事项
不要伪造产品界面、截图、统计数字、研究数据、品牌标志、引语或作者肖像。不要复制文章全文、另造副标题、添加水印或署名；避免乱码、错别字、裁切标题、俗套霓虹渐变和与正文无关的装饰。

## 完成标准
画面比例符合目标，标题逐字准确，主题与摘要一致，隐喻易懂；成图符合 Hardy 网站的现代黑白灰编辑视觉，并有足够留白。只生成这一张封面，不输出拼图、联系表、备选画面或解释文字。
```

## 编译与保存

- 将字段替换成文章实际内容；删除不适用项并补足最相关的版式决定。
- 完整标题是必需文本。不得为了缩短提示词把完整标题替换成另写的营销短句。
- 视觉背景提示词只使用摘要与提炼后的主体，不把整篇文章发送给图像模型。
- 先将完整提示词保存为 `assets/<article-slug>/<run-id>/prompts/cover.md`，再生成图像；每张正文图分别保存一个简短提示词文件。
- 每次生成后只接收图像工具明确返回的本轮产物路径、URL或图像字节。不要扫描宽泛的缓存目录，避免误拿其他文章或过去任务的图。
- 如果提示词或图像工具不支持精确中文排版，生成无字底图后使用可控排版工具；确实没有合成能力时，保留底图并说明标题尚未叠加。
