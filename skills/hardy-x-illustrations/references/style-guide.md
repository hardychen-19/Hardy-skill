# 正文编辑图解视觉

## 已认可方向

目标：看懂知识点。默认 16:9 横向、浅色空白、柔和哑光立体对象与小比例 Hardy IP、清楚短标签和关系。主体知识内容为主，人物辅助参与。参考已认可的[正文样稿](../assets/body-diagram-approved-v1.png)，用于校准人物尺度、材质、标签可读性与留白；不复制其三窗口和指点动作到所有文章。

## 统一语法

- 暖白或中性白底，连续留白；不默认搭房间、舞台、景观。背景只在本身承载知识点时加入。
- 低饱和蓝灰、深墨、奶油白为基底，少量暖黄或绿色说明重点和状态。关系线、标签与立体物件保持清楚对比；不用激烈红黑或霓虹光。
- 角色与对象使用柔和哑光块面、圆润边缘和轻微接触阴影；线条表达结构，材质不写实，不堆毛发、纹理、刻线或纸张颗粒。
- 知识主体通常占中部大部分，人物约 15%–20% 画面宽度起排；根据动作和标签可读性调整。人物头身比直接跟随身份图，不由正文占比推算。
- 对象丰富度来自正确关系、前后状态和有作用细节；不用重复大卡片填满画面。必要的示意窗口不是所有题材的通用模板。
- 标签短、准确、贴近对象；关系箭头只在具有方向含义时出现。一个简短结论可保留，长说明回正文。标签能读清优先于材料逼真。

## 不同图型

截图使用真实材料与明确标记，不改造为立体界面。数据使用可核对图表或表格，数字、单位、时间范围保持原意。概念关系使用原文支持的对象和连接，不假装真实产品页面。物理隐喻不能混淆解析、存储、传输和部署。

同篇保留身份、材质、色彩规则，构图、角色动作和对象随知识点变化。封面尺寸、吸睛效果、宣传标题不属于正文默认设计。
