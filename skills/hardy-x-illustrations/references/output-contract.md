# 输出规则

## 预览或单张试图

只生成请求的数量，保存最终图与提示词，说明用途、对应段落和实际路径。没有要求完整插图时不改文章；预览通过自动检查也只能标 ready，用户明确认可后标 approved。

## 完整文章配图

每轮使用不冲突的资源目录，提示词先保存；保留工具原图和已选最终图。输出配图版 Markdown 和一个清单。原稿只读，新稿重名时新建版本，不复用上一轮路径覆盖资产。

清单记录：原稿路径、配图版路径、当前个人角色参考、参考版本、主题 ID、图像工具、状态及未完成项。每图记录序号、用途、原文依据、唯一插入锚点、图型、图片路径、提示词路径、替代文本、实际宽高、验收结果和用户是否确认。未生成或失败项必须单独记录，不写入最终 Markdown 的图片引用。

图片与提示词路径相对于清单目录。个人照片和素材只在用户输出目录中管理，不把私人路径写入技能源码。角色原图与样稿不需要每轮复制，但清单应明确本轮读了哪张参考。

## Markdown 验收

新增链接相对于配图版；目标文件实际存在。锚点唯一、位于完整段落边界，不能落进代码围栏、表格、链接或原图说明。不要为了插图改写原文。

配图版换目录时，原图、视频、引用式链接和附件要复制必要资源或重算相对路径。带空格路径用适当 Markdown 路径表达，不把目录拼接后的不存在路径当成功。检查新旧引用都可解析，不重复插入同一图。

协议模式沿用随包产物协议，普通目录清单不登记到固定工作区索引。本模块 cover_path/cover_prompt_path 均为 null，不把文末关注图填进封面字段。用户确认某张图不等于批准整篇成稿或发布；不推断对外操作授权。


## 文末关注图交付

完整文章默认在原文最后一个完整段落之后追加一张；用户不要、已有合适关注图或仅要正文单张预览时，按范围处理，不重复插入。关注图单独计数、记录用途为 ending、替代文本、最终插入锚点、完整提示词和实际尺寸；复用时记录来源并说明没有重新生成。它属于 images，不新增顶层协议类型或封面字段。生成失败时保持原文，记录未完成项，不插入不存在的文件。
