# 正文图提示词编译

每图先填字段，再编成一份完整提示词。截图与精确数据使用真实素材或可控图表，不走模型猜测。

## 必要字段

原文依据、插入锚点、单一知识点、图型、对象职责与关系、误读边界、角色身份参考、动作及可见结果、准确短标签、系列差异、输出名与替代文本。

## 成图提示结构

```text
制作一张独立的 16:9 正文编辑图解。
原文依据与要解释的知识点：{evidence_and_takeaway}
图型、对象职责与准确关系：{diagram_structure}
必须避免的误读：{misreading_limits}
准确短标签：{verbatim_labels_or_none}

角色参考只约束身份、头身比、衣着和哑光立体材质，不照抄插兜站姿与背景。
{character_action_and_visible_result_or_no_character}
人物为边缘辅助，约 15%–20% 画面宽度起排，主体知识对象占主位。
使用浅色空白、低饱和蓝灰与奶油色、柔和哑光体积、清楚轮廓和轻微接触阴影。
关系线与标签清楚可读。若箭头代表顺序、传输、指向或条件，要与原文一致。
依据知识点选择图型，不套浏览器框、三栏或完整室内场景。
标签短、准确；不生成宣传标题、真实软件操作截图、无依据道具或数字。
只生成这一张，不用拼图代替多张。
```

实际执行时替换所有字段，不把占位符原样传给工具。先保存最终使用的提示词，再调用生成；修正时保存新版本和具体修改目标。

## 教程示例

“先跑通模板、补齐内容、再加效果”可用三个相继状态；必须保留这是推荐顺序的性质。已有路线图已说明该点时不重复画。域名、服务器、文件关系使用职责图，不把解析画成文件搬运。首月费用与续费比较用原文数据的可控表格。点击路径用真实截图。
