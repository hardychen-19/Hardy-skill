# 文末关注图

## 范围与文案

完整文章配图默认在原文结尾之后追加一张关注图；用户明确不要时省略。仅做单张正文试图、分析分镜或标注截图时不附加。文章已有合适关注图时保留，用户要求修改则替换，不重复追加。

默认准确短文案：`关注我`、`往期优质长文`、`主页查看`。用户指定文案优先，不自行增加账号名、网址、二维码、虚构按钮行为、关注奖励或收益承诺。用户选择正文用途不意味着批准发布。

## 构图与人物

![文末关注图示例](examples/04-ending-follow.png)

该生成图是构图参考，不是必须复刻的完整模板。沿用同篇选定主题的背景、材质、配色和人物；默认柔和立体才使用暖白与哑光体积，其余主题依对应规则。示例只约束关注图的用途与主次。

人物身份、比例和衣着沿用当前个人档案。动作可为递出文章、展示作品或邀请查看；人物辅助文案和对象，不占满画面、不遮字。主次按新图重排，不照搬示例中的人物实际占比。对象可以是文章、笔记或作品页，按当前文章选择，不强制堆三张纸或浏览器框。不生成真的软件操作界面；图里的“关注我”是文案而非可点击功能。

## 提示词与生成

先保存完整提示词，再使用宿主图像工具。身份参考只约束身份、比例与衣着，材质服从主题，不照抄姿势。提示词应明确用途、准确文案、人物动作、相关对象、统一视觉、可读性和禁用项。

示例生成意图：制作一张独立的 16:9 文末关注图，使用当前个人角色和本篇正文选定的主题视觉；人物把与主题相关的文章页递给读者，保持小比例，背景与留白服从选定主题；清楚显示“往期优质长文”“主页查看”，把“关注我”融入同一构图。文案、人物与物件共享光源、透视和阴影，避免文字像后贴上去。无二维码、假网址、关注数据、奖励承诺、额外宣传语或大头像。

按用户实际文案、文章对象和人物动作编译，不原样套用所有示例。正文解释图与关注图分别生成，不能用拼图替代独立产物。

## 保存与检查

保存为本轮资源目录中的独立图片和提示词，例如 `ending-follow.png` 与 `prompts/ending.md`。记录实际尺寸和本轮工具返回文件；不扫描缓存猜测产物。

插入到原文最后一个完整段落之后，清单的 images 项记录用途 ending、替代文本、插入锚点、图片与提示词路径。cover_path 与 cover_prompt_path 仍为 null。检查文案准确、角色一致、字体可读、位置唯一与链接可解析；失败时登记未完成，不写入不存在的图片引用。复用已有图时记录其来源并说明未重新生成。
