# Hardy X 正文配图

默认目标是让读者看懂知识点。先读全文，确定图要解释的一个判断，再选择图型、具体对象和角色动作。画面采用已认可的“小比例立体 IP＋知识主体＋短标签＋浅色留白”。实际生图依赖宿主图像工具，本技能不内置生成 API。

## 输入与范围

接受 Markdown 文件、正文文本或 `x.draft.v1`。复用已给出的文章、输出目录、角色和样式，不让用户重复提供。普通“配图”默认正文；仅明确请求封面时读取[封面蓝图](references/cover-prompt-blueprint.md)，封面与正文单独设计。

仅要求分析时给精简分镜；要求生成或插入时完成真实图片文件和 Markdown 副本。只试一张时生成一张预览，不自动批量生图或改原文。用户已认可的样稿可继续使用；未认可的候选不升级为角色或风格规范。

## 选图：理解增益决定数量

通读全文并检查已有图片与附件，再读取[选图与构图](references/planning.md)。数量按独立理解难点决定，不设字数配额，不按章节平均分配；已有截图或图解说明清楚的节点不重复画。短文本或没有独立解释价值的节点可以不配图，并说明原因。

| 内容需求 | 执行路径 |
| --- | --- |
| 真实按钮、菜单、网页状态 | 真实截图＋清楚标注，不能生成假操作界面 |
| 精确数量、金额、坐标、时间 | 可核对的表格或可控图表，逐项检查单位与期间 |
| 职责、关系、因果、条件 | 编辑图解，明确对象与关系方向 |
| 制作过程或状态变化 | 步骤、对照或动作图解，一图一个知识点 |
| 只有气氛或重复文字 | 通常省略 |

拿不到操作素材时说明缺口，可以跳过该图或改画明确的概念图；不以伪截图补位。观点、预测、建议和事实分开，不把推荐顺序画成技术必然条件。

## 人物与视觉

生成概念图前读取[风格指南](references/style-guide.md)与[人物标准](references/character.md)。默认使用随包的已确认角色图；用户指定其他已确认角色时优先。新增角色或大幅换装不自动当作已确认版本。

人物固定身份、比例、衣着与哑光立体材质；动作、方向与视线随知识点变化。不复刻身份图的插兜姿势，不画半页大胸像。人物通常从画面宽度约 15%–20% 起排，知识对象占主位；该比例不是人物实际头身比，也不是整组主体占画面的比例。

意象与物件来自正文，不能把浏览器、卡片、城市、云、纸页或机器人套进每篇文章。关系图可有必要标签和线条，但不搭无解释作用的房间或舞台。人物无理解作用时可省略，截图和数据图不强行放 IP。

设计物件、动作或关系结构时，按需读取[物件演示案例](references/examples.md)，选择最接近当前知识点的一张查看。三张为用户选定的参考，分别展示反馈回路、分类检索和条件分支；借鉴统一材质与角色参与方式，不固定照搬人物大小、字数、物件或构图。

## 生成与验收

1. 为每个选中节点记录分镜：唯一插入锚点、原文依据、单一知识点、图型、对象职责与关系、人物动作、必要短标签、误读边界、替代文本。整个系列检查动作与构图节奏。
2. 按[提示词蓝图](references/body-prompt-blueprint.md)编译完整提示词，逐张先保存再生成。传入身份参考，标明只约束身份与材质；首张或风格偏离时查看样稿，不把样稿构图作为默认参考输入。
3. 知识结构、准确文字与可读性优先。复杂标签或精确数据使用可控工具；无法稳定写准的长句放回正文，不为“融合”牺牲字形。
4. 按[验收清单](references/body-qa.md)检查。最多两轮针对性修正，每轮只处理一个主要问题；仍失败就记录未完成，不把计划或旧文件当新图交付。检查通过是可审阅状态，用户明确认可才标记 approved。
5. 图像绑定只接受当前调用明确返回的文件。记录实际尺寸，比例不符时重新生成或用宿主图像编辑能力适配，不拉伸、不谎报尺寸。

## 保存与 Markdown

用户指定输出目录优先；没有时保存文章旁。普通文件交付每轮新建 `assets/<article-slug>-x-illustrations/<run-id>/`，保存图片、完整提示词和清单，不覆盖旧版。工具原始图保留；最终图不能只停留在生成缓存中。

完整配图默认另存 `<原名>-正文配图版.md`，重名加运行标识。按唯一锚点在段落后插入相对图片链接，保留原稿、段落顺序和事实，不插进代码块或表格。已有本地图片、视频及附件在配图版换目录后仍须可解析。详细交付字段和预览模式见[输出规则](references/output-contract.md)。

固定工作区模式读取已有配置，接收 ready/approved 的 `x.draft.v1`，输出待审阅的 `x.illustrated-draft.v1`；无封面时封面字段 null。登记和路径规则见[产物协议](references/artifact-protocol.md)。普通指定目录不擅自更改工作区配置。仅在用户要求发布包且有相应工具时准备本地包，不对外发布。
