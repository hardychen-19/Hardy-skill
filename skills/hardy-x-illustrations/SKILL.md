# Hardy X 正文配图

默认目标是让读者看懂知识点。先读全文，确定图要解释的一个判断，再选择图型、具体对象和角色动作。默认沿用“小比例个人角色＋知识主体＋短标签＋浅色留白”的柔和立体画风，可选手绘笔记、清淡水彩、深色科技。实际生图依赖宿主图像工具，本技能不内置生成 API。

## 输入与范围

接受 Markdown 文件、正文文本或 `x.draft.v1`。复用已给出的文章、输出目录、角色和样式，不让用户重复提供。本技能当前范围为正文解释图与文末关注图，暂不提供封面生成。完整文章配图默认在原文结尾之后附一张关注图；用户明确不要时省略。正文数量按理解增益判断，关注图另计。保留用户已有素材，不因范围调整删除原稿里的封面。

仅要求分析时给精简分镜；要求生成或插入时完成真实图片文件和 Markdown 副本。只试一张时生成一张预览，不自动批量生图或改原文。用户已认可的样稿可继续使用；未认可的候选不升级为角色或风格规范。

## 首次角色选择与主题

首次没有可用角色档案、且用户未明确指定人物或上传照片时，先只问一个问题：

> 第一次使用，你想直接使用随包的 Hardy IP（不用照片），还是上传一张自己的照片，生成专属角色？

等待选择后按[人物标准](references/character.md)执行，并记住选择供后续复用。明确选择 Hardy IP 时使用随包角色；选择个人角色时只需上传一张清晰个人照片，生成并保存专属角色。用户已经指定人物或上传照片就直接按其选择继续，不重复询问；已有档案直接复用，不再索要照片。用户同时给文章就继续配图；只有照片就交付角色与主题入口。角色文件保存在个人配置区，安装目录保留随包素材。无图像工具时如实说明。

按[主题选择](references/themes.md)使用用户指定主题，其次复用个人档案主题，未选择时默认柔和立体。四套主题的提示词和实际预览均随技能提供；不需要用户自己写完整提示词。主题影响画风，不能改变原文事实、关系和数据。

## 选图：理解增益决定数量

通读全文并检查已有图片与附件，再读取[选图与构图](references/planning.md)。数量按独立理解难点决定，不设字数配额，不按章节平均分配；已有截图或图解说明清楚的节点不重复画。短文本或没有独立解释价值的节点可以不加正文解释图；完整文章的文末关注图仍按用户要求处理。

| 内容需求 | 执行路径 |
| --- | --- |
| 真实按钮、菜单、网页状态 | 真实截图＋清楚标注，不能生成假操作界面 |
| 精确数量、金额、坐标、时间 | 可核对的表格或可控图表，逐项检查单位与期间 |
| 职责、关系、因果、条件 | 编辑图解，明确对象与关系方向 |
| 制作过程或状态变化 | 步骤、对照或动作图解，一图一个知识点 |
| 只有气氛或重复文字 | 通常省略 |

拿不到操作素材时说明缺口，可以跳过该图或改画明确的概念图；不以伪截图补位。观点、预测、建议和事实分开，不把推荐顺序画成技术必然条件。

## 人物与视觉

生成概念图前读取[风格指南](references/style-guide.md)与[人物标准](references/character.md)。先复用个人角色档案；首次用照片建立角色，自动检查后标记 ready 并可继续配图，用户明确认可才标 approved。随包 Hardy 图可供明确选择 Hardy IP 的用户直接配图，不需要上传照片。

人物固定身份、比例与衣着，材质和线条服从所选主题；动作、方向与视线随知识点变化。不复刻身份图的插兜姿势，不画半页大胸像。人物通常从画面宽度约 15%–20% 起排，知识对象占主位；该比例不是人物实际头身比，也不是整组主体占画面的比例。

意象与物件来自正文，不能把浏览器、卡片、城市、云、纸页或机器人套进每篇文章。关系图可有必要标签和线条，但不搭无解释作用的房间或舞台。人物无理解作用时可省略，截图和数据图不强行放 IP。

设计物件、动作或关系结构时，按需读取[物件演示案例](references/examples.md)，选择最接近当前知识点的一张查看。三张为用户选定的参考，分别展示反馈回路、分类检索和条件分支；借鉴统一材质与角色参与方式，不固定照搬人物大小、字数、物件或构图。

## 文末关注图

完整配图或明确要求末尾图时读取[文末关注图规则](references/ending-card.md)。沿用同篇 IP、材质与配色，默认短文案为“关注我”“往期优质长文”“主页查看”。用户指定文案优先；不编造账号、网址、二维码或关注收益。已有合适末尾图时保留或按要求复用，不重复追加。只生成单张正文预览、只分析分镜或只标注截图时，不附加关注图。

## 生成与验收

1. 为每个选中节点记录分镜：唯一插入锚点、原文依据、单一知识点、图型、对象职责与关系、人物动作、必要短标签、误读边界、替代文本。整个系列检查动作与构图节奏。
2. 按[提示词蓝图](references/body-prompt-blueprint.md)和当前主题规则编译完整提示词，逐张先保存再生成。传入身份参考，标明身份参考固定身份、衣着与比例，画风由当前主题决定；首张或风格偏离时查看样稿，不把样稿构图作为默认参考输入。
3. 知识结构、准确文字与可读性优先。复杂标签或精确数据使用可控工具；无法稳定写准的长句放回正文，不为“融合”牺牲字形。
4. 按[验收清单](references/body-qa.md)检查。最多两轮针对性修正，每轮只处理一个主要问题；仍失败就记录未完成，不把计划或旧文件当新图交付。检查通过是可审阅状态，用户明确认可才标记 approved。
5. 图像绑定只接受当前调用明确返回的文件。记录实际尺寸，比例不符时重新生成或用宿主图像编辑能力适配，不拉伸、不谎报尺寸。

## 保存与 Markdown

用户指定输出目录优先；没有时保存文章旁。普通文件交付每轮新建 `assets/<article-slug>-x-illustrations/<run-id>/`，保存图片、完整提示词和清单，不覆盖旧版。工具原始图保留；最终图不能只停留在生成缓存中。

完整配图默认另存 `<原名>-正文配图版.md`，重名加运行标识。按唯一锚点在段落后插入相对图片链接，保留原稿、段落顺序和事实，不插进代码块或表格。已有本地图片、视频及附件在配图版换目录后仍须可解析。详细交付字段和预览模式见[输出规则](references/output-contract.md)。

固定工作区模式读取已有配置，接收 ready/approved 的 `x.draft.v1`，输出待审阅的 `x.illustrated-draft.v1`；本模块的 cover_path 与 cover_prompt_path 固定为 null，关注图登记在 images 中。登记和路径规则见[产物协议](references/artifact-protocol.md)。普通指定目录不擅自更改工作区配置。仅在用户要求发布包且有相应工具时准备本地包，不对外发布。
